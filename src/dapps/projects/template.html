DNZN // RAKE rake.dnzn.dev

Transparent fund distribution on Ethereum. A distribution is one address with a published table of beneficiaries — anything it receives, ETH or ERC-20, is paid out by that table when anyone calls distribute().

  • Every change to the table is queued behind a public time lock — beneficiaries see it coming
  • Same addresses on Ethereum, Base, Sepolia and Base Sepolia
  • Dapp and widget served from the chain by a contract of their own

Alpha software, unaudited — source on github.

DNZN // GW44 web gateway

A web gateway for contract-hosted, on-chain dapps — front ends a contract serves itself through ERC-8244 html() and ERC-5219 request().

  • Two static files, ~16 KB — self-host it or put it on a CDN
  • A service worker calls the contract from the visitor's browser — no gateway server, nothing cached
  • Each contract gets its own origin, so one dapp's document cannot touch another's

Alpha software, not externally audited.

DNZN // DxKit microframework

A headless microframework for building composable dapps. Routing, lifecycle management, event bus, plugin registry — zero DOM ownership.

DNZN // WNS Resolver browser extension

Chrome extension that detects ethereum addresses on any page and resolves them to their Wei Name Service (WNS) primary names in-place.

  • Batched resolution via Multicall3 — multiple addresses resolved in a single RPC call
  • Robust set of configuration options — custom rpc, caching, cooldown, etc
  • Zero external dependencies — vanilla javascript, no build requirements

Production deployment is pending feedback and testing — development installation via git.
